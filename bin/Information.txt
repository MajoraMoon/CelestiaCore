### Notes:
All required libraries are included in the `lib/` folder. No external dependencies are needed as they will be compiled with the project. 
(Tested the compilation on an arch based Linux distribution and on Windows)

## Steps

1. **Clone the repository:**

   ```bash
   git clone https://github.com/MajoraMoon/CelestiaCore.git
   cd CelestiaCore
   ```

2. **Create a build folder:**

   ```bash
   mkdir build
   cd build
   ```

3. **Run CMake with build type:**

   - For **Linux**:
     ```bash
     cmake .. -DCMAKE_BUILD_TYPE=RelWithDebInfo
     ```

   - For **Windows (MinGW)**:
     ```bash
     cmake .. -G "MinGW Makefiles" -DCMAKE_BUILD_TYPE=RelWithDebInfo
     ```

4. **Build the project**:
   ```bash
   cmake --build . --parallel
   ```


5. **Run the executable:**

   ```bash
   ./bin/CelestiaCore
   ```
